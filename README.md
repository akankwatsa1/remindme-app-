# RemindMe — Tasks & Reminders

A professional, **screen-reader accessible** to-do list with date & time reminders.
Built in pure HTML/CSS/JavaScript — no frameworks, no internet connection needed.

- Add an event with a date and time (e.g. "Internet data expires").
- Get an **advance reminder** (e.g. 1 day / 1 hour / 5 minutes before).
- When the date and time is reached, an alert fires and the event is **marked done automatically**.
- Repeating events — daily, weekly, monthly, yearly, **or any custom interval
  (e.g. every 30 days for data top-ups)** — automatically schedule the next occurrence.

---

## How to run it right now (HTML version)

1. Open the folder `remindme-app`.
2. Double-click **`index.html`** (it opens in your browser — Chrome or Edge recommended).
3. Click **"New event"**, fill in a title, date and time, pick how early to be reminded, and save.

> Tip: to test reminders quickly, create an event a few minutes in the future and choose
> **"5 minutes before"** or **"At the due time"**. An in-app alert + chime will appear.
> System notifications (even when the window is in the background) appear after you click
> **"Enable notifications"**.

### Important limitation of the pure-HTML version
While running in a browser, reminders only fire while the app page is open.
The **packaged desktop version** runs in the tray and reminds you even when the
window is closed. See below.

## How to package it as an installable app (already done — v1.3.0)

The Windows build is ready in `F:\remindme-app-dist\`:

```
RemindMe Setup 1.3.0.exe              ← installer (double-click to install)
RemindMe-Portable-1.3.0.exe           ← PORTABLE version — runs straight from a USB stick
win-unpacked\RemindMe.exe             ← portable-unpacked version (no install needed)
```

- The installer is a standard NSIS setup program with the app icon, a Start Menu
  shortcut and an optional desktop shortcut.
- The **portable exe** needs no installation: copy it to any USB drive and double-click
  it there — settings and events are kept in the app's own data folder (per user), and
  everything still works (tray, notifications, reminders).
- The build was written to `F:\` because the `C:` drive on this machine is currently
  full — free up space on `C:` if you want to rebuild into the project folder instead.

> **Why does Windows show a warning when I run it?**
> The app is not code-signed (a paid code-signing certificate is needed for that).
> Click "More info → Run anyway" — this is normal for unsigned apps. Signing is a
> simple future step once you have a certificate.

### Reminders when the app is "closed" (desktop version)

The desktop app has a **system tray icon**. Closing the window does not quit the app —
it hides to the tray, and the main process keeps your reminders scheduled, firing
**native Windows notifications** even when the window is closed or minimized.
Clicking a notification reopens the app on that event. To fully stop it, right-click
the tray icon → **Quit RemindMe**.

### Start with Windows (auto-start)

In **Settings → Start with Windows**, turn the toggle **On** to make RemindMe start
quietly in the tray whenever you sign in to Windows — reminders are then always on,
even if you never open the app. (Only available in the installed desktop version.)

To rebuild after making changes:

```bash
npm install          # only the first time (needs internet)
npm start            # run the app as a desktop window (development)
npm run dist         # build installer + portable exe (or -c.directories.output=...)
```

The app icon lives in `assets/` (`icon.ico` for Windows, `tray.ico` for the tray,
`app-icon.png` for the web) and is generated by `node scripts/make-icon.js` —
no image tools needed.

## Features

| Area | Details |
| --- | --- |
| Events | Title, date, time, category, notes, repeat (none / daily / weekly / monthly / yearly / custom — e.g. every 30 days) |
| Reminders | Advance notice from 1 day down to "at the due time", snooze (5/15/60 min), sound chime, system notifications |
| Desktop app | System tray icon, close-to-tray, **reminders fire as Windows notifications even when the window is closed**, click a notification to open the event, **auto-start with Windows** |
| Auto-done | Event is marked done when its date & time is reached (you can also tick it early, or reopen it if not repeating) |
| Accessibility | Full keyboard support, ARIA live regions, accessible dialogs, focus management, high-contrast themes, reduced-motion support, **screen-reader-friendly plain text date/time fields (no cursor jumping)** |
| Data | Saved locally (localStorage) — **Export / Import JSON backup** included |
| Extras | Search, filters (All/Pending/Overdue/Done), light & dark theme, keyboard shortcuts (`N` new event, `/` search), stats summary, sample events |

## Keyboard shortcuts

- `N` — open the "New event" dialog (when not typing)
- `/` — jump to search
- `Tab` / `Enter` / `Esc` — standard dialog and button navigation

## Accessibility notes

- Semantic HTML (`header`, `main`, `h1–h3`, `ul/li`, `<label>` for every field)
- Native `<dialog>` elements with `aria-labelledby` / `aria-describedby` — focus moves into
  the dialog and is trapped; `Esc` closes
- A polite live region announces status messages; the reminder alert is an `alertdialog`
- Every control has an accessible name (`aria-label`, `aria-pressed`, `title`)
- WCAG-friendly contrast in both light and dark themes, `prefers-reduced-motion` respected
